# **SPARTA RECOMP**

God of War: Sons of Sparta (PS4) recompiled to run natively on Android, rather than through a full emulator.

Developed using **Orbs-sdk**, my SDK for recompiling PlayStation 4 and PlayStation 5 games.

## **REQUIREMENTS**

- Your own legally obtained copy of God of War: Sons of Sparta (PS4). No game files are included.
- When prompted, select the folder containing the game's `eboot.bin` file, extracted by you from your own copy of the game.
- Android device with Vulkan support and a compatible GPU driver.
- **Minimum device tested:** Snapdragon 8 Gen 2 with **Turnip v27.0.0.R1**.
- **Mali GPUs are not supported or tested.**

## **PERFORMANCE**

- Testing has been performed on a Snapdragon 8 Gen 2 with Turnip v27.0.0.R1.
- Performance and compatibility may vary depending on the device and GPU driver.

## **STATUS**

**Experimental test build.** This is an early build intended for testing, and stability, performance, and compatibility are not guaranteed.
